# TreeRecall Pro — Anti-Gravity Edition 🌿

**思考を重力から解放する。物理演算ベースの無限ツリー型メモツール。**

ブラウザだけで動作する完全スタンドアロン版です。インストール不要・サーバー不要・インターネット接続不要（フォント読み込み時を除く）。

## ✨ 特徴

- **物理演算ノード** — ノードが自然に浮遊し、互いに反発・引力でレイアウトされる
- **マルチボード** — 複数のボードを階層管理できる
- **Recall サイドバー** — 過去に入力したテキストを記録・検索・ドラッグ再利用
- **長方形グループ** — ノードをエリアで囲んでグループ化
- **共有コード** — Base64エクスポートで他ユーザーとボードを共有
- **JSONエクスポート / インポート** — 全データをJSONファイルで保存・復元
- **localStorage自動保存** — データはブラウザに自動保存される

## 🚀 使い方

`index.html` をブラウザで開くだけで動作します。

```
ダブルクリック → ノード作成
ノードをドラッグ → 移動
右端の●をドラッグ → 他ノードへ接続
ダブルクリック（ノード） → テキスト編集
```

## 🗂️ ファイル構成

```
treerecall-web/
└── index.html   # CSS・JS全て内包した単一ファイル
```

## 📦 データの保存

- ブラウザの `localStorage` に自動保存されます
- 💾「保存」ボタンで全データを JSON ファイルにエクスポート可能
- 📂「開く」ボタンで JSON ファイルをインポート可能

## 🔗 共有方法

「共有」ボタン → 「共有コードを生成」→ コードをコピーして相手に渡す  
受け取った側：「ボード」→「コードでインポート」にペースト

## 🌐 GitHub Pages でホスティング

このリポジトリを GitHub Pages で公開すれば、URL を共有するだけで誰でもアクセスできます。  
Settings → Pages → Branch: `main` / Folder: `/ (root)` を選択。
